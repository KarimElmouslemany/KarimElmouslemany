### 🎮 Counter-Strike 2 Statistics Tracker [↗](https://github.com/KarimElmouslemany/counter-strike-2-tracker)

A mobile statistics tracker for Counter-Strike 2, built using **React Native and Expo**.

**✨ Key Features:**
1. Integrates the Steam Web API and Leetify API
2. Processes player data to calculate statistics including:
3. K/D ratio
4. Accuracy
5. Win rate
6. Headshot percentage
7. Displays weapon and map performance statistics
8. Displays recent match results and player rank

**Project Status: Currently in development and continuing to be improved.**
